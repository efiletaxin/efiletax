# eFileTax Mobile App

A React Native (Expo) mobile application for [eFileTax.in](https://efiletax.in) — India's GST & Income Tax Consultant platform.

## Features

- **Onboarding** — 4-slide onboarding flow showcasing key services
- **Authentication** — Login, Register, and OTP verification screens
- **Home** — Dashboard with quick actions, upcoming deadlines, promo banners, and popular services
- **Services** — Searchable, filterable list of all 9 tax & compliance services
- **Service Detail** — Tabbed detail page with Overview, Features, Documents, and FAQs
- **Tax Calculator** — FY 2024-25 income tax calculator for both New and Old regimes with slab breakdown
- **Order Tracking** — Track all service orders with real-time status and step-by-step progress
- **Profile** — User profile, preferences, support, and document management

## Services Covered

1. ITR Filing (all forms)
2. GST Registration
3. GST Return Filing
4. Company/LLP/OPC Registration
5. Udyam (MSME) Registration
6. TDS Return Filing
7. Accounting & Bookkeeping
8. Annual Compliance (ROC)
9. Import Export Code (IEC)

## Tech Stack

- **Framework**: Expo SDK 51 + React Native 0.74
- **Navigation**: Expo Router (file-based routing)
- **UI**: Custom components with LinearGradient, Ionicons
- **Language**: TypeScript

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with **Expo Go** app on your phone to run it instantly.
